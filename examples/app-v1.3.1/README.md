# v1.3.1 界面源码摘录

本版包含 7 份原样前端源文件：公共样式与布局、任务列表和操作区、学生筛选、手机工作台、中文弹窗标签。摘录不能独立运行完整系统。完整路径与 SHA256 见 [source-manifest.json](source-manifest.json)。

参考 [Element 设计原则](https://element.eleme.cn/#/zh-CN/guide/design)，使用项目既有 Vue 3 / Element Plus，不新增或降级依赖。业务 API 和权限沿用 v1.3.0。
