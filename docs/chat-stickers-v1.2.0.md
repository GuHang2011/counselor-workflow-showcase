# 内部聊天表情包 · v1.2.0

在“内部聊天”打开联系人后，点击输入框旁的“表情”；也可以在功能搜索中输入“表情包”找到内部聊天。本版按确认的范围提供内置表情包和常用表情。

## 使用方式

- **办公表情包**：12 张原创校园机器人图片，包含收到、好的、谢谢、辛苦了、加油、点赞、稍等一下、已完成、请查收、合作愉快、早上好、抱歉。点击后显示“待发送”预览，可移除；点击“发送”才会发给对方。每条消息可带一张表情包，也可同时填写文字或添加附件。
- **常用表情**：24 个常用表情加入输入框，与文字一起发送。电脑端插入到光标位置，移动 H5 加到文字末尾；不会超过现有消息长度限制。
- **草稿和重试**：切换会话分别保留当前草稿，清空草稿会同时移除表情包。失败时保留选择；重试同一消息不会创建第二条。草稿只保留在当前页面会话，刷新或退出前请先发送或清空。
- **接收与历史**：对方直接看到图片，历史消息重新打开仍可查看；会话列表显示表情名称，旧客户端会显示 `[表情包：收到]` 等说明。

“已完成”等表情包只是聊天表达，不会改变任务进度、审核或业务记录。表情图片随应用本地打包，不向第三方网站加载图片。本版不包含自定义表情上传、收藏、GIF 动图和贴纸商店。

## 权限与兼容

服务端仅接收 12 个固定表情标识，拒绝未知值、路径、外部网址和非字符串数据。发送前仍校验会话成员与当前联系范围；停用、角色或班级范围变化后不得访问原会话。表情包不能绕过附件所属人、安全检查或过期校验。表情标识参与重复发送校验，更改表情不能复用原消息标识。

本版使用现有加密消息记录增加可选字段，无数据库结构迁移。建议前后端同时更新；回退旧版本时，已发送表情仍有文字说明可读。微信、原生 App 仍须真实环境验收，本轮验证范围为电脑网页、响应式网页和移动 H5。
