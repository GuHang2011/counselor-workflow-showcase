# Element 风格界面优化

版本：v1.3.1，2026-11-01。

参考用户指定的 [Element](https://element.eleme.cn/#/zh-CN) 及其 [设计原则](https://element.eleme.cn/#/zh-CN/guide/design)：一致、反馈、效率、可控。项目使用 Vue 3 / Element Plus，沿用现有组件体系，不引入面向 Vue 2 的 Element UI 包。

| 检查到的问题 | 本版处理 |
| --- | --- |
| 圆角、间距、字号和文字对比度不一致 | 统一输入框、按钮、表格、弹窗和页面留白；选中导航使用主题色，正文和提示采用更清晰的灰阶 |
| 任务发布和导入按钮分散，筛选与输出混排 | 任务范围置左、导入和发布置右；搜索和状态筛选组成独立区域，刷新、导出与打印集中排列 |
| 学生页面重复标题、嵌套留白过大，查询依赖占位提示 | 简化为名单标题与人数，增加可见字段标签，支持回车查询，常用筛选默认收起 |
| 窄屏横向查看表格时丢失办理入口 | 任务和学生表格固定右侧操作列，表格内部滚动，页面本身不横向溢出 |
| 手机首页需要横滑才能找到逾期或待审核分类 | 五类待办使用网格直接显示，点击后保留明确的选中状态 |
| 弹窗关闭按钮的读屏名称显示内部翻译键 | 补全“关闭对话框”中文标签；长表单保留可滚动内容和固定底部操作区 |
| 登录页与办公页面风格不同 | 采用浅蓝底色、统一输入框和按钮，保留智能工程技术学院的电路与学工插画 |

学生列表点击“查询”或按回车后更新；“清空筛选”恢复默认列表。“常用筛选（可选）”可用鼠标或键盘展开。导出与打印始终使用已展示的列表，保留原有服务端授权检查。

电脑端工作任务的导入、发布、导出和打印入口保持明确文字。手机端刷新与“更多”集中在筛选区下方；“更多”中提供导出、打印。移动 H5 独立客户端本版未改动，手机适配说明指电脑网页的响应式界面。

验收使用隔离环境和合成资料。界面专项覆盖 320、390、768、1024、1440 像素宽度，检查回车查询、无结果反馈、清空筛选、键盘展开、导入弹窗、任务范围、输出菜单及五类待办切换。发布时另外运行完整既有浏览器与 HTTP 验收；结果随版本证据交付。

本版无数据库结构迁移、权限策略或依赖版本变更。升级包保留 v1.3.0 的后端程序，替换为本版前端；按现有宝塔部署流程备份并更新站点静态文件，保留服务器配置、数据和密钥。生产服务器尚未执行更新。
