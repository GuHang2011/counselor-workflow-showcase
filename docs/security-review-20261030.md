## 正式上线仍需完成

1. **框架与 JDK**：后端仍是 Spring Boot 2.3.7、Java 8 兼容代码，已明显陈旧。本轮没有冒然升级涉及 H2 文件格式、Java 基线和 Spring 行为的整套后端。正式公网开放前，应在独立升级分支完成受维护 JDK / Spring Boot 迁移、Java 依赖扫描、MySQL 集成与恢复验证；本包宜先在受控校内环境验收。
2. **宝塔 MySQL 启动故障**：本机无法确认服务器问题已解决。仍须结合宝塔数据库错误日志、数据目录权限、磁盘空间和配置实际排查。H2 测试通过不能替代 MySQL 验收。
3. **目标服务**：验证 HTTPS / Nginx 响应头、数据库仅内网可达、ClamAV 实际扫描、FFmpeg 实际转码、密钥文件权限及备份恢复。测试环境允许未配置扫描的合成附件，正式部署保持 `ERP_MEDIA_REQUIRE_SCAN=true`。
4. **AI 外发**：默认继续禁用。配置服务地址属于超级管理员的受信操作，当前没有实现学校域名白名单；填写前需批准服务商并配置网络出口规则。真实供应商和真实密钥未参与本轮测试。
5. **部署模型**：继续使用单实例；登录失败计数在内存中，重启会重置，不适合直接扩展多实例。若使用代理，应保留仅信任本机 Nginx 的真实地址配置；不要信任客户端自报的转发头。

更新前备份数据库、附件和原始密钥，解压到新目录，校验 ZIP 与 `SHA256SUMS`，按宝塔指南切换版本。未执行真实服务器发布。
