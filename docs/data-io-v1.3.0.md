# 导入、导出与打印

版本：v1.3.0，2026-11-01。

| 使用位置 | 导入 | 导出与打印 |
| --- | --- | --- |
| 学生名单与档案 | 原有 CSV / XLSX 模板、检查、确认导入 | 当前列表的学号、姓名、学院、专业、年级、班级、学籍状态 |
| 工作任务 | 下载模板与接收人账号清单，检查后确认发布 | 按当前任务范围和筛选导出 CSV，打印任务表 |
| 宿舍与安全 | 导入新床位，重复床位不覆盖入住信息 | 顶部按钮输出筛选后的床位；住宿变动、卫生记录分别有输出按钮 |
| 谈话跟进、入团入党、卫生、归档 | 按原有业务流程登记 | 按当前可见列表导出和打印，保留中文栏目、状态及北京时间 |
| 内部聊天 | “导入文件”选择本地附件，完成检查后再点击发送 | 会话顶部“导出 / 打印”，按日期输出完整历史，支持 TXT / CSV |

任务与床位导入支持 UTF-8 CSV 和 Excel 的第一个工作表（.xlsx），每批最多 500 行、10 MB。列名采用下载模板中的中文名称，也兼容对应英文列名。每个任务行指定一名接收人，使用工号/学号对应的登录账号，不能用重名姓名猜测。日期请设为文本，例如 `2026-12-01 17:00`，按北京时间解释；不接受 Excel 日期序号。

导入先检查，逐行显示错误原因并允许下载错误清单。所有行检查通过后，任务点击“确认导入并发布任务”，床位点击“确认导入床位”。预检有效期为一小时；确认时重新检查权限、接收人、日期和现有床位，任何一行不满足条件则整批不写入。重复确认同一预检批次不会重复创建。重新上传文件会生成新的批次，不应将已完成文件作为新批次重复导入。

学生名单沿用原有导入机制；转班、审核结果、任务完成进度、宿舍实际入住交接仍通过对应业务操作办理。附件导入表示上传为待发送文件，不会将本地聊天文本伪造为系统历史消息。

聊天导出一次最多 5000 条，超过时需要缩小日期范围；不限于页面当前加载的消息。不填写日期表示全部记录，填写的结束日期包含当天。导出包含发送时间、发送人、文字、表情说明及附件名称，附件原文件仍从聊天消息下载。移动 H5 支持这些输出操作；微信小程序和原生 App 未新增系统打印接口。

打印会生成独立资料表，不打印侧栏、按钮、输入草稿或只显示一部分的滚动列表。可在浏览器打印窗口选择打印机或“另存为 PDF”；手机浏览器是否提供打印取决于系统支持。CSV 含 UTF-8 BOM，并转义公式开头的内容；如需保留学号前导零，请在 Excel 导入 CSV 时将学号列指定为文本。

附件新增 TXT / CSV（UTF-8）支持，沿用 20 MB 文档上限、上传队列、安全检查和下载授权；不合格编码和二进制控制字符会被拒绝。正式环境仍应配置附件扫描。导出和打印由服务端重新确认权限，聊天仅会话参与者可导出，账号管理员不能因此读取他人的聊天或学生私密联系方式。

本版不新增数据库结构迁移；业务使用现有加密记录存储。任务/床位预检可纳入既有“资料留存”策略，按管理员批准的保留期处理。

验收记录：147 项后端测试、37 项浏览器回归、15 项 HTTP 检查及重启持久化通过；另通过 8 组导入导出实际浏览器专项检查。演示截图仅包含演示账号与合成资料，未在生产环境操作。
