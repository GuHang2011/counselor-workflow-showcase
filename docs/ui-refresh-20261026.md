# 辅导员工作台界面更新 · 2026-10-26

本次更新记录了智能工程技术学院辅导员系统近期的界面整理和可用性改进。截图来自隔离测试环境，账号、任务和学生姓名均为虚构演示数据。

## 本次上传的内容

- `assets/login-smart-engineering.png`：突出学院名称和校园工程场景的登录页。
- `assets/dashboard-shortcuts.png`：辅导员首页的常用入口、待办列表和个人任务进度。
- `assets/feature-search.png`：通过 `Ctrl/Cmd + K` 打开的功能搜索面板。
- `app.js`、`index.html`、`styles.css`：在静态展示页加入功能搜索交互，支持关键词过滤、键盘快捷键和直接跳转。

## 交互调整

1. 首页先展示“今天要处理什么”，把学生名单、谈话跟进、请假返校和材料收集放到常用入口。
2. 待办按“需要我处理、今天到期、7 天内到期、逾期未完成、待我审核”分组，减少辅导员反复查找。
3. 管理员看到全员任务进度，辅导员默认看到自己的任务和学生跟进事项，角色之间的入口保持清晰。
4. 功能搜索支持功能名称和用途关键词，搜索结果只展示当前展示页已公开的入口；生产系统会继续按角色权限生成结果。
5. 登录页使用学院名称和工程技术场景作为识别元素，减少与工作无关的口号内容。
