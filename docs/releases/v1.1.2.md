# v1.1.2 · 任务办理与功能设计优化

发布日期：2026-10-31。修复辅导员在提醒跳转、手机审核、任务期限、跟进时间及统计读取中的 7 类问题，继续采用清爽校园办公界面。

## 本版变化

- 提醒直接打开具体事项，重复点击同一事项可再次办理；已提交任务的提醒结束不再误写成任务完成。
- 手机支持全选当前筛选范围内的待审核任务，筛选改变后排除隐藏项，退回仍需填写批注。
- 未开始任务不提前催办；新任务不能使用已过期截止时间；更新跟进时必须填写未来的下次提醒时间。
- 页面逾期状态每分钟更新；个人统计失败时可重试，避免假零、旧数字及统计口径误解。

## 验证

135 项后端测试、13 项共享逻辑测试、37 项浏览器回归、15 项隔离 HTTP 检查、聊天 HTTP 链路及重启持久化通过。新增 3 项后端回归先复现再修复；新增 5 项浏览器场景使用隔离登录与合成接口数据测试边界交互。完整问题清单与测试说明见 [功能设计复查](../functional-review-20261031.md)。

## 宝塔更新与回退

1. 先备份当前数据库、附件、配置和旧程序包，确认备份可恢复；本版不要求新增 SQL 迁移。
2. 在维护时段停止应用服务，按既有宝塔部署指南替换后端 JAR 与前端静态文件，保留服务器专属环境配置与密钥。不要覆盖数据目录。
3. 启动服务并检查健康接口、登录、权限、任务提交审核、提醒和附件。浏览器重新加载静态资源。产品版本以包内 `VERSION` 和 `release-manifest.json` 为准；JAR 文件名保留组件名称。
4. 失败时停止新服务，恢复上一版前后端与对应配置，核对业务数据兼容性后启动；不要覆盖已发布标签或旧部署包。

完整部署包只在本地交付，GitHub 发布审阅代码摘录、说明与合成数据截图。v1.1.1 的公开 frontend/backend 目录整理保留，历史标签不变。

隔离 H2 测试不代表目标 MySQL、真实 HTTPS、病毒扫描、视频处理和备份恢复已验收。旧框架及依赖告警仍需处理；外部 AI 未联调。本轮未直接操作生产服务器。
