# v1.3.0 · 导入、导出与打印

发布日期：2026-11-01。

学生名单增加导出与打印，工作任务和宿舍床位提供模板、检查、错误清单及确认导入。宿舍床位、人员变动与卫生记录分别输出，避免下载内容与页面含义不一致。业务资料统一使用中文表格和专用打印排版。

内部聊天支持按日期导出完整记录（TXT / CSV）和打印，保留文字、表情说明及附件名称。文件导入/发送新增 UTF-8 TXT / CSV，电脑和移动 H5 均可使用。具体格式、范围和操作见 [使用说明](../data-io-v1.3.0.md)。

导出重新校验当前权限；导入经过预检及事务内复核，同一批次重试不会重复写入。CSV 输出防止公式注入，打印使用文本节点，文本附件保持下载授权和附件响应头。

隔离环境验证：147 项后端测试（含本版 9 项专项测试）、37 项浏览器回归、15 项 HTTP 检查、聊天与重启持久化通过；电脑端类型检查、生产构建及移动 H5 构建通过。另完成 8 组实际浏览器专项检查，覆盖 CSV/XLSX 导入、错误清单、断网重试、筛选导出、CSV 公式转义、打印/PDF、聊天完整历史及手机文件下载。未进行微信小程序/原生 App 真机打印或生产 MySQL 验收。

无新增 SQL 迁移。宝塔更新前备份数据库、附件、环境配置和上一版程序，同时更新前后端；保留服务器密钥，核对版本及 SHA256。此次不直接部署生产，目标 MySQL、HTTPS、扫描与备份恢复需在部署环境验收。
