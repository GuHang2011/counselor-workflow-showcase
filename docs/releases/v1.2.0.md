# v1.2.0 · 聊天表情包与常用表情

发布日期：2026-11-01。

内部聊天新增 12 张原创办公表情包和 24 个常用表情。电脑和手机可选择、预览、移除并发送；支持按会话保留草稿、发送失败重试、历史显示和可读会话摘要。具体操作与边界见 [使用说明](../chat-stickers-v1.2.0.md)。

服务端校验固定表情标识，继续执行会话权限和附件安全检查；消息标识包含表情选择，避免重试重复。图片本地打包，旧客户端可显示文字说明。本版不包含自定义上传、收藏或 GIF。

无新增 SQL 迁移。宝塔更新前备份数据库、附件、配置与上一版程序，核对 VERSION、产物清单和 SHA256；前后端一起替换，保留服务器的环境变量和密钥。回退使用上一版前后端及对应配置。

验证：138 项后端测试、37 项浏览器回归、15 项隔离 HTTP 检查、聊天及重启持久化通过；电脑和移动 H5 构建通过。另完成 7 组表情包交互专项验证。微信和原生 App 未做真机验证。

本轮未直接部署生产，目标 MySQL、HTTPS、附件扫描、备份恢复及旧框架风险仍需现场验收。公开 GitHub 仓库仍提供展示、源码摘录及演示截图，完整部署包本地交付。
