# v1.1.0 · 校园办公界面与安全改进

发布日期：2026-10-30。首次统一使用产品语义版本号，归档本轮界面改版和 11 类安全与易用性修复。

## 使用体验

登录页采用浅色校园办公风格和学院主题插画；首页先展示待办与进度，管理员查看人员进度，辅导员聚焦本人事项。统一表格、导航、表单和弹窗层级；任务详情支持直接办理，关闭已修改表单前确认，搜索支持键盘操作。

## 安全与可靠性

1. 拒绝退出或切换账号前发出的旧成功响应，避免跨账号数据回填。
2. 断网退出立即清除本地身份；服务端注销失败时准确提示，不宣称旧令牌已被远程撤销。
3. 五处 CSV 导出统一防范公式注入，覆盖空白、控制字符和 BOM 前缀。
4. 登录失败独立按账号和来源限流，清理过期记录并限制内存占用。
5. AI 调用使用实际保存的模型、地址和密钥，重启后首次调用也恢复配置。
6. AI 密钥加密保存、不回显；留空保留、显式清除，更换服务地址时重新确认密钥。
7. AI 配置仅超级管理员可见；错误在当前弹窗显示，外部调用授权只读展示。
8. AI 远程地址要求 HTTPS，禁止重定向，限制响应 1 MiB 和输出 token。
9. 关闭附件页面或退出时取消下载，防止旧预览覆盖和资源残留。
10. 宝塔模板增加 CSP、防嵌入、权限策略及 HTTPS HSTS；浏览器验收使用同一 CSP。
11. 更新 Vue、Lodash、Rollup 等依赖；桌面 npm 审计由 25 项降至 9 项。

## 更新与回退

本轮没有新增数据库表结构迁移。先备份数据库、附件和原加密密钥，将 `release-v1.1.0.zip` 解压到新目录，校验 ZIP 和包内 `SHA256SUMS`，保留原环境配置及数据目录，再按宝塔部署指南切换。不要覆盖或重新初始化现有数据库。程序回退可切回上一发布目录；恢复数据必须使用经过验证的备份方案。

本地日期候选包 `release-20261030-security.zip` 保留不动；新版包复用完全相同的前后端产物。GitHub 公开仓库继续提供源码摘录、更新说明、合成数据截图和脱敏验收摘要；不包含真实数据、密钥或完整部署程序。

## 已知限制

- Spring Boot 2.3.7 / Java 8 兼容基线较旧，需规划受维护框架与 JDK 迁移。
- 桌面依赖仍有 9 项包级告警（3 高、6 中），不能据本地功能测试宣称安全问题全部清零。
- 宝塔 MySQL 启动故障、真实 HTTPS、ClamAV、FFmpeg 和目标主机备份恢复尚需实机验证；H2 测试不替代 MySQL 验收。
- AI 外发默认关闭，未调用真实外部服务。登录限流为单实例内存状态，重启后重置。
- 本版本适合先在受控校内环境验收，不代表已经完成正式服务器发布。
