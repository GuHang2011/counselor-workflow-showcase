# v1.1.3 · 辅导员日常操作与界面优化

发布日期：2026-11-01。本版集中改善首页、任务办理、手机布局、发布表单和汇报编辑，逐项解决 8 类用户体验问题。

- 手机任务卡片突出状态、材料要求、截止时间和办理按钮；下载打印集中到“更多”。
- 切换任务范围不再遗留筛选，已发布任务显示各阶段进度；逾期与临期任务优先排列。
- 读取失败明确提示重试，避免假空列表和旧结果导出，保留当前汇报编辑。
- 发布表单集中说明提交与审核要求，增加快捷截止日期；长弹窗保留底部操作按钮。
- 重新生成汇报或新闻前确认覆盖；汇报标记生成时间和范围变化。
- 修复首页分类选中效果与编辑框名称，统一字号、留白、状态和轻量反馈。

详细问题、解决方式、验证与使用边界见 [用户体验复查](../ux-review-20261031.md)。

验证：15 项共享逻辑测试、37 项浏览器回归、15 项隔离 HTTP 检查、聊天与重启持久化通过，另完成本轮浏览器交互专项检查。后端产物未变，沿用 v1.1.2；该版 135 项后端测试未在本轮重复运行。

无新增 SQL 迁移。宝塔更新前备份数据库、附件、配置与旧程序，维护时段替换包内前后端，保留服务器环境变量和密钥。核对包内 VERSION、清单和校验值；失败时恢复上一版前后端与对应配置。禁止覆盖旧版本包或标签。

隔离 H2 验收不替代目标 MySQL、HTTPS、病毒扫描与备份恢复验证；本轮未部署生产、未调用真实 AI。公开仓库为审阅摘录，完整部署包本地交付。
